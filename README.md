# Food Tracker

แอปบันทึกอาหารภาษาไทย สำหรับดูรายการ เพิ่ม แก้ไข และลบว่ากินอะไร มื้อไหน ราคาเท่าไหร่ กี่คน พร้อมรูปถ่ายจากกล้องได้ (ไม่บังคับ)

ไม่มีหน้าล็อกอิน

## ฟีเจอร์

- หน้าต้อนรับ แล้วไปหน้ารายการอาหาร
- ดูรายการอาหารทั้งหมด
- เพิ่มรายการอาหาร และถ่ายรูปประกอบได้
- แก้ไขหรือลบรายการอาหาร

## สแต็ก

- Flutter
- Riverpod
- go_router
- Supabase

ข้อมูลเก็บในตาราง `food_tracker_tb` และรูปเก็บในบัคเก็ต `food_tracker_bk` รายละเอียดสคีมาและนโยบายอยู่ที่ `supabase/schema.sql`

## วิธีรัน

คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่าโปรเจกต์ Supabase ของคุณ

```bash
flutter pub get
flutter run --dart-define-from-file=.env
```

ถ้ายังไม่ได้ตั้งค่า Supabase แอปจะเปิดด้วยข้อมูลตัวอย่างในเครื่อง

## วิธีสร้างไฟล์ APK

```bash
flutter build apk --release --dart-define-from-file=.env
```
